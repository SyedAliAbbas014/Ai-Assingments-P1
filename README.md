Problem 1: Install OpenAI SDK and Create a First AI Agent
Environment setup performed using uv (a fast Python package/environment manager), a Google Gemini API key, and the openai-agents SDK.
Setup steps completed:
1. Installed uv via PowerShell.  2. Verified installation with 'uv --version'.  3–4. Created a project folder and opened it in VS Code.  5. Ran 'uv init .' to initialize the project.  6. Created a virtual environment with 'uv venv'.  7. Activated it with '.venv\Scripts\activate'.  8. Installed python-dotenv with 'uv add python-dotenv'.  9. Generated a Gemini API key from Google AI Studio.  10. Stored the key in a .env file.  11. Installed the Agents SDK with 'uv add openai-agents'.
.env file
GEMINI_API_KEY='<student's own Gemini API key>'
